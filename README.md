# Оценка числа π и интегралов методом Монте-Карло

Данный репозиторий содержит программную реализацию компьютерной модели для численного вычисления числа \(\pi\) и четырех «неберущихся» интегралов на единичном отрезке. В работе реализованы и сравнены два классических вероятностных подхода: метод попаданий (Hit-or-Miss) и метод выборочного среднего (Mean Value). Программа позволяет исследовать сходимость оценок, строить доверительные интервалы и проверять статистическую адекватность модели.

## 2. Физико-математическая модель

*   **Метод попаданий (Hit-or-Miss):** В ограничивающий прямоугольник (для интегралов это квадрат \([0,1] \times [0,1]\)) случайно бросаются точки \((X, Y)\). Если точка попадает под график функции (\(Y \le f(X)\)), она засчитывается. Оценка интеграла равна доле попавших точек.
*   **Метод выборочного среднего (Mean Value):** Вычисляется среднее значение функции в случайно сгенерированных точках \(X\) на отрезке \([0,1]\). Оценка интеграла равна этому среднему.
*   **Оценка погрешности:** Для каждой оценки вычисляется стандартная ошибка (SE) по выборке. На ее основе строится 95% доверительный интервал (ДИ) с использованием квантиля нормального распределения (\(z \approx 1.96\)).
*   **Закон сходимости:** Согласно теории Монте-Карло, среднеквадратическая ошибка (RMSE) должна убывать пропорционально \(O(1/\sqrt{N})\), где \(N\) — число испытаний.

## 3. Валидация модели

Перед основными экспериментами были проведены детерминированные тесты (функция `validate_implementation()`) для проверки корректности кода и математических формул.

### Тест 1. Непрерывность функций в нуле
**Цель:** Проверка обработки неопределенностей \(0/0\) для функций \(\frac{\sin x}{x}\) и \(\frac{\ln(1+x)}{x}\).
**Результат:** Программа корректно использует непрерывное продолжение функций в точке \(x=0\) (обе функции принимают значение 1).

### Тест 2. Интеграл единицы
**Цель:** Проверка масштабирования и подсчета на простейшей функции \(f(x) = 1\).
**Результат:** Оба метода дают точное значение 1 без статистической ошибки (SE = 0), что подтверждает правильность логики.

### Тест 3. Воспроизводимость случайных чисел (Seed)
**Цель:** Проверка работы генератора случайных чисел.
**Результат:** При фиксированном `seed` программа выдает абсолютно идентичные результаты при повторных запусках.

### Тест 4. Сверка с эталонной квадратурой
**Цель:** Проверка модуля `scipy.integrate.quad` на простых полиномах (интеграл от \(x\) и \(x^2\)).
**Результат:** Все проверки пройдены (код `validation.csv` сохраняется в папку результатов).

### Тест 5. Проверка нормальности ошибок
**Цель:** Убедиться, что распределение стандартизованных ошибок \(T_r = \frac{\hat{\theta} - \theta_{ref}}{SE}\) подчиняется нормальному закону \(N(0,1)\).
**Результат:** Как видно на гистограммах (см. раздел 4.5), эмпирическое распределение ошибок хорошо согласуется с теоретической кривой.

### 4.6. Основные выводы
1. **Скорость сходимости:** Оба метода подчиняются теоретическому закону $O(1/\sqrt{N})$. С увеличением \(N\) разброс оценок стабилизируется.
2. **Эффективность методов:** Метод выборочного среднего (Mean Value) показал себя значительно точнее. Его дисперсия меньше, что видно как по узким доверительным интервалам, так и по смещенным вниз графикам RMSE.
3. **Доверительные интервалы:** В подавляющем большинстве случаев 95% интервалы накрывают истинные значения. Гистограммы ошибок подтверждают их нормальное распределение, что говорит о корректности примененных статистических формул.
